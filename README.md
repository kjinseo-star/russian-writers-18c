# 18세기 러시아 작가 관계도

『18세기 러시아 작가 사전』(Словарь русских писателей XVIII века)의 표제어 간 참조를 작가의 출신, 교육, 국내외 수학, 생몰연대에 연결한 연구용 웹 애플리케이션입니다. 데이터 가공·재구성 및 웹 설계는 서광진 (경북대) / Seo Kwangjin (KNU) / Со Кванг Чжин (КНУ)이 담당했습니다. 이 저장소에는 **화면 v08·연구 데이터 v05**의 소스와 브라우저 배포본을 함께 실었습니다.

[브라우저에서 104인 관계도 열기](https://kjinseo-star.github.io/russian-writers-18c/dist/)

공개 웹에서 관계도, 검색, 인물별 근거와 생몰연표를 바로 열어볼 수 있습니다. 제보 저장과 관리자 검토는 별도의 서버를 연결한 운영판에서 지원합니다.

## 무엇을 읽을 수 있나

사전 항목을 하나의 노드로, 그 항목이 다른 표제어를 가리키는 참조를 방향선으로 표시합니다. 전체 참조망은 780명·4,440개 방향선입니다. 참조를 보낸 횟수와 받은 횟수의 합으로 순위를 매겨 상위 100위의 동률을 모두 포함했습니다. 합계가 20보다 큰 사람은 99명, 20인 사람은 5명입니다. 이 104인 사이의 참조 1,439개에서 자기참조 하나를 제외한 1,438개가 표시됩니다. 실제 친분·서신·영향의 성격은 사전 본문과 관련 사료에서 각각 판독해야 합니다.

- 관계도에서 사람을 선택하면 인접한 방향 참조가 강조됩니다. 사람 수와 참조 수는 개별 카드에 구분해서 표시합니다.
- 출신, 출생지, 수학 기관·교사, 해외 수학, 당시 국가·현재 위치, 생몰연대 등을 조합할 수 있습니다. 교육기관 수학에는 확인된 청강·중단도 포함합니다. 해외 수학 ‘기록 미확인’은 해외 학습이 없었다는 판정과 구별합니다.
- ‘출처와 근거’에서 러시아어 원문, 사전 권·인쇄면·PDF쪽, 판정 근거 및 불확실성을 확인할 수 있습니다. 선택한 인물만 생애 연표에 올릴 수 있습니다. 한국어·영어·러시아어 화면은 같은 인물과 원문을 공유합니다.

## 바로 실행하기

Python 3가 설치된 컴퓨터에서 이 저장소의 최상위 폴더를 열고 아래 명령을 실행합니다. 브라우저에서 `http://127.0.0.1:8000/`을 열면 관계도·인물 검색·연표·CSV를 사용할 수 있습니다. 정적 실행에 npm이나 API 키는 필요하지 않습니다.

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory dist
```

정적 실행에서 제보 저장·비공개 관리함은 서버 연결이 필요합니다. 빈 로컬 SQLite 데이터베이스와 가상의 관리자 계정으로 제보 흐름을 확인하려면 **Node.js 24** 환경에서 `npm run dev -- --port 3000`을 실행하고 `http://127.0.0.1:3000/`을 엽니다. 이 미리보기 서버는 로컬 컴퓨터에만 연결됩니다.

## 데이터 재현 및 검증

아래 두 명령은 Python 3 표준 라이브러리만 사용합니다. 첫 명령은 판독이 끝난 인물·필드 자료와 CSV·TSV에서 104인 선정, 양쪽 차수, 중복, 자기참조를 대조하고 `dist/app-data.json`을 다시 만듭니다. 둘째 명령은 v08 보존 사본에 대한 SHA-256과 인물·참조·출신·교육 자료의 주요 수치를 검사합니다.

```sh
python3 scripts/prepare_public_data.py
python3 scripts/audit_release.py
```

기준 결과는 인물 104명, 방향 참조 1,438개, 핵심 필드 1,352개, 교육 사건 315개, 교사·지도·양육 등 관련 기록 127개, 계획·이주 전 교육을 포함한 국외 교육 기록 52개입니다. 기본 국외 학습 판정을 충족한 인물은 21명이고, 이들 사이의 참조는 61개입니다. 같은 현행 사건표에서 확인된 사건에 도시명이 있는 사람을 고르면 역시 21명입니다. 이 기준은 러시아 이주 전 교육을 포함합니다. 두 집단에 모두 속하는 사람은 17명입니다. 학습 여부 확인을 요구하지 않고 도시명만 세면 22명이 됩니다. 출신이 미분류인 인물을 한쪽 끝에라도 포함하는 참조는 719개입니다. 이 수치들은 원 사전 전체에 대한 모집단 추정치가 아닙니다.

## 소스에서 빌드하기

Node.js 24, npm, Python 3, npm 레지스트리 연결이 필요합니다. 의존성 버전은 `package-lock.json`에 고정했습니다. 화면은 React·TypeScript로, 관계도는 Cytoscape.js로 구현했습니다. esbuild가 브라우저 파일과 서버용 Worker를 생성합니다.

```sh
npm ci
npm run build
npm run typecheck
npm run check:ui
node scripts/check-language.mjs
npm run check:reports
python3 scripts/audit_release.py
```

`src/graph-layout.json`은 v08의 고정 좌표입니다. 배포된 코드와 자료의 SHA-256 기준값은 `docs/v08-checksums.json`을 참조하십시오. 이 공개본에서는 데이터 재구성, 해시·집계 검사, Node.js 24의 SQLite 기반 제보 검사를 실행했습니다. 패키지 레지스트리에 연결할 수 없는 제작 환경에서 npm 전체 재빌드는 재실행하지 못했습니다.

## 파일 구성과 판본 경계

| 경로 | 내용 |
|---|---|
| `dist/` | index.html, app.js, app.css, 사용 라이브러리 고지, app-data.json |
| `src/` | 웹 화면, 사전·지리 서지, 언어 자료, 좌표 |
| `source_data/Persons_EDGES.csv`, `Persons_links.tsv`, `Readme_graph.md` | 오레호프가 제작한 기초 사전 참조망의 공개 자료와 작성 원칙 |
| `source_data/reviewed-v05.json.gz` | 현재 뷰어의 인물, 판정, 원문 근거, 표시 규칙. 중복을 줄이기 위해 압축했고 참조선은 두 원표에서 재생성합니다. |
| `scripts/` | 공개 데이터 조립·검증, 빌드·화면 시험·로컬 미리보기 |
| `worker/`, `drizzle/` | 제보 처리, 관리자 검토 이력, 빈 데이터베이스를 만드는 스키마 |

공개본의 데이터 조립 스크립트는 인물 판독을 다시 수행하는 대신 보존한 판독값과 원 관계망으로 v08 표시 데이터를 재현합니다. 빌드는 이 공개 입력을 사용하며 특정 서비스 인스턴스 식별자를 복사하지 않습니다. 약 4MB의 중복 서버 번들은 `npm run build`로 재생성합니다.

## 제보 기능과 접근 범위

소스 공개와 운영 중인 검토 사이트의 접근 권한은 별도입니다. 이 저장소만으로 서비스 접근, 제보 내용, 운영 관리자 권한이 부여되지 않습니다. 제보와 관리자 검토 이력은 연구 JSON에 쓰지 않고 Worker에 연결된 별도 D1 데이터베이스에 기록합니다. 배포 환경에서는 신뢰할 수 있는 인증 게이트웨이가 이용자 정보를 검증·전달하도록 구성해야 합니다. 해당 게이트웨이 밖에서 관리자 권한을 활성화하는 로컬 미리보기 코드는 운영에 사용하지 않습니다. 이메일 통지는 별도 설정이 필요합니다.

## ChatGPT 활용 공개

연구자가 자료 범위와 판정·표시 방식을 정하고, ChatGPT의 도움을 받아 사전 판독, 구조화, 코드 작성, 검토를 진행했습니다. 30인 예비 판독과 재판독을 거쳐 추가한 74인의 주판독에는 GPT-6 Astra(max), 이후 104인 전원의 독립 재독에는 GPT-6 Astra(ultra)가 기록되어 있습니다. 초기 웹 구현에서 자료 변환과 화면을 담당한 두 작업에는 GPT-6.1 Sol(high), 독립 웹 검토에는 GPT-6 Astra(xhigh)를 요청했습니다. 후속 교육·역사지리 보완은 판독·지리·엑셀 작업을 나누어 수행했고, 그때의 세부 모델 설정은 확인되지 않습니다. 원면 선택 대조와 데이터 무결성 검사를 수행했으며 모든 셀의 인간 연구자 최종 교감은 진행 중입니다.
